# Bundled components

- **Node.js 24.19.0** — local engine runtime. License and notices: `licenses/Node-LICENSE.txt`. Source: https://github.com/nodejs/node/blob/v24.19.0/LICENSE
- **ripgrep 15.2.0** — local Unity metadata search. MIT/Unlicense: `licenses/ripgrep-LICENSE-MIT.txt` and `licenses/ripgrep-UNLICENSE.txt`. Source: https://github.com/BurntSushi/ripgrep/tree/15.2.0
- **PCRE2 10.45** — included in the ripgrep build. Notices: `licenses/PCRE2-LICENCE.txt`. The sync engine does not require PCRE2 search mode.

The interface uses the .NET Framework libraries installed on Windows.
